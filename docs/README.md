# Field Techy Documentation

This repository contains comprehensive documentation for the Field Techy project, a platform connecting clients with field technicians. The docs are organized into categories: **Core Processes** (rarely updated, foundational docs) and **Sprint Artifacts** (frequently added during sprints, evolving with project progress).

## Overview
- **Purpose:** To provide a centralized knowledge base for processes, guidelines, and technical details, ensuring consistency and efficiency for the development team.
- **Format:** Documents are written in Markdown and built with mdbook for easy navigation.
- **Scope:** Covers SDLC processes, implementation details, testing strategies, and more. Future additions include requirement specifications, API docs, and user guides.

## Documentation Structure

### Core Processes
- Comprehensive, stable guides that define frameworks and standards.
- **SDLC Document:** Guide to the Software Development Life Cycle using Scrum.
  - Sub-sections: Scrum Framework Overview, Roles, Artifacts, Events, Phases Mapping, Git Flow (with Branching Strategy and Workflow Examples), Code Review and Assignment, QA Processes, Escalation of Issues, Scrum Board, Team Communication, Onboarding.

### Sprint Artifacts
- Documents added and updated frequently as the project progresses through sprints.
- **Test Design Documents:** Outlines testing approaches, test cases, and reports for sprints.
- **Web Documents:** Details complex implementations and components for the web application.

## Getting Started
- Use `mdbook serve` to view the docs locally.
- Refer to the SUMMARY.md for the full table of contents.
- Contributions: Update docs via PRs, following the SDLC guidelines.

For questions, contact the development team or refer to the SDLC Onboarding section.
